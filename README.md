# ВЕСПЕР: Цена несказанного — Episode I

Самостоятельная браузерная 2D-игра на HTML, CSS, Canvas и JavaScript. Не требует серверного бэкенда или внешних библиотек.

## Запуск локально
Откройте `index.html` в современном браузере. На первом нажатии активируются аудио-контекст и возможность русской речи, если браузер/устройство поддерживает `speechSynthesis`.

## Управление
- A/D или стрелки — движение
- J — удар
- K — удар ногой
- L — блок
- I — Отзвук
- Enter / Space — подтверждение в диалогах
- На сенсорных устройствах используйте экранные кнопки.

## Публикация через GitHub Pages
1. Создайте публичный репозиторий.
2. Загрузите `index.html` в корень репозитория.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch, ветку `main`, папку `/(root)`, сохраните.
5. После публикации откройте URL GitHub Pages на ПК или телефоне.

## Что включено
- Один сюжетный эпизод: вступление, три боя (включая финального босса), развязка и эпилог.
- Рисованные в Canvas героини с разными костюмами, деталями и оружием.
- Сенсорное и клавиатурное управление.
- Процедурная оригинальная музыкальная тема и звуковые эффекты через Web Audio API.
- Русские реплики через встроенный синтез речи браузера. Голос зависит от доступных системных голосов; это синтез, а не студийная запись актёров.
- Сохранение прогресса через localStorage на том же устройстве и в том же браузере.
- Адаптивный интерфейс для мобильных и настольных экранов.

## Ограничения, которые важно знать
- Персонажи отрисованы процедурно в Canvas: это стилизованная иллюстрация, а не покадровая hand-painted анимация или 3D.
- Музыка генерируется синтезатором, а не является отдельной студийной аудиозаписью.
- Озвучка использует `speechSynthesis`; доступность и тембр русского голоса зависят от браузера и устройства.
- Сохранение локальное и не синхронизируется между устройствами.
